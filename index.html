📖 สำรองข้อมูลและกู้คืนด้วยไฟล์ JSON (JSON Backup & Restore)

ส่งออกข้อมูลสถานะระบบทั้งหมด (ยูนิต, โซน, เรทราคา, วันหยุด, รายการคำขอ) เป็นไฟล์ `.json` หรือกู้คืนข้อมูลกลับเข้าสู่ระบบ

💾 1. สำรองข้อมูล (Export JSON Backup)

ดาวน์โหลดไฟล์สำรองข้อมูลปัจจุบันลงในคอมพิวเตอร์ หรือคัดลอกโค้ด JSON ไปเก็บไว้

♻️ 2. กู้คืนข้อมูล (Import JSON Restore)

เลือกไฟล์ `.json` ที่เคยสำรองไว้เพื่อนำข้อมูลทั้งหมดกลับเข้าสู่ระบบทันที

🧬 ข้อมูลของระบบ (Diagnostics & Webhook Logs)

ระบบคีย์บันทึกข้อมูลแบบ Cloud Serverless ประสานงานผ่าน Google Apps Script API อัตโนมัติ
